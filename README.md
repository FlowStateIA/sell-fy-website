# Sell-Fy Marketing Website

Sitio web de marketing para Sell-Fy, construido con React, TypeScript y Vite.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite 8
- **Styling**: TailwindCSS 4.2 + shadcn/ui
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Inter Font
- **Deployment**: Vercel

## 🎨 Design System

- **Primary Color**: Red `#dc2626`
- **Background**: Dark theme (`gray-900`, `gray-950`)
- **Effects**: Glassmorphism, subtle glow gradients
- **Inspiration**: Linear.app style (dark theme, smooth animations)
- **Language**: Spanish

## 📦 Installation

```bash
npm install
```

## 🛠️ Development

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🏗️ Build

```bash
npm run build
```

## 🔍 Lint

```bash
npm run lint
```

## 🚢 Deployment

This project is configured for deployment on Vercel:

1. Push to GitHub
2. Import project in Vercel
3. Vercel auto-detects Vite configuration
4. Deploy!
